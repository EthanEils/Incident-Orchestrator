# Glossary

**Incident**  
A service-impacting event requiring alerting, acknowledgement, and resolution.

**Escalation Policy**  
A structured set of rules defining who gets paged, when, and via which channels.

**Orchestration**  
Durable workflow executed through Azure Durable Functions handling delays, retries, and external events.

**Timeline Event**  
Append-only log entry documenting significant changes in incident state.

**On-Call Assignment**  
Materialized representation of which user is responsible at a given time.

**External Event**  
A signal (ACK, escalation confirmation, etc.) raised into a Durable Function instance.

**RBAC**  
Role-Based Access Control, implemented via Entra ID roles/groups.
